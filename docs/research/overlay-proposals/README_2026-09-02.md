# Overlay proposals (DRAFT)

Propuestas generadas por el **generador de overlays** (`feat/overlay-generator`).

## Flujo

1. `make overlay MODEL=…` o `make overlay-batch` (dry-run por defecto).
2. Con `WRITE=1`: stub fiable → `config/model_overlays/ollama.json`; este directorio recibe el markdown DRAFT.
3. **Revisar** la sección DRAFT (thinking levels, sampling, recipes, quirks).
4. Copiar a mano lo aprobado al overlay. **No** aplicar DRAFT a ciegas.

[`docs/specs/SPEC_OVERLAY_GENERATOR_2026-09-02.md`](../specs/SPEC_OVERLAY_GENERATOR_2026-09-02.md)

## Archivos

Cada propuesta: `{model-id-sanitizado}_YYYY-MM-DD.md` (p. ej. `gemma4-31b-cloud_2026-09-02.md`).
