## Parámetros comunes Ollama (`/api/chat`)

Todos los modelos cloud comparten la misma API local. Parámetros transversales:

- **`options`**: `temperature`, `top_p`, `top_k`, `min_p`, `num_predict`, `num_ctx`, `seed`, `stop`, `repeat_penalty`, `repeat_last_n`
- **`think`**: modelos con capacidad thinking — ver doc de cada modelo
- **`tools`**, **`format: "json"`**, **`stream`**
- **`messages[].images`**: modelos con capacidad `vision`

En este proyecto: defaults en `config/provider_params.json`; presets por modelo en `config/ollama.json` (la mayoría de cloud aún sin preset dedicado).
