# gemma4:31b-cloud

Modelo cloud de Google DeepMind (Gemma 4) en Ollama — denso multimodal con razonamiento y 256K de contexto.

## Ficha técnica

| Campo | Valor |
|-------|-------|
| **Identificador Ollama** | `gemma4:31b-cloud` |
| **Modelo remoto** | `gemma4:31b` |
| **Arquitectura** | gemma4 (Dense) |
| **Parámetros** | ~32.7B (30.7B + embeddings) |
| **Cuantización cloud** | BF16 |
| **Contexto** | 262 144 tokens (256K) |
| **Embedding length** | 5376 |
| **Capacidades** | completion, thinking, tools, vision |
| **Modalidades** | Texto + imagen (sin audio en 31B) |
| **Capas** | 60 |
| **Vocabulario** | 262K tokens |

## Descripción

Gemma 4 31B es el modelo **denso** de workstation de la familia Gemma 4 de Google DeepMind. Ofrece razonamiento configurable, soporte nativo de rol `system`, function calling y comprensión multimodal con resolución de imagen variable.

En Ollama Cloud es una de las opciones **más baratas** ($0.14 input) con visión incluida. Sustituye a Gemma 3 (12B/27B/4B) en la hoja de ruta de retiros de Ollama (julio 2026).

## Fortalezas

- **Excelente relación precio/capacidad**: $0.14 / $0.40 por 1M tokens.
- **Benchmarks sólidos para 31B**: MMLU-Pro ~85.2%, LiveCodeBench ~80%, GPQA ~84.3%.
- **Multimodal**: MMMU-Pro ~76.9%, OCR/documentos con presupuesto de tokens visual alto.
- **Contexto 256K** con resultados MRCR 128k ~66.4%.
- **Thinking configurable** vía plantilla (`<|think|>` en system prompt; Ollama gestiona template).
- **Rol system nativo** en Gemma 4 (mejora vs Gemma 3).
- **Tools / agentic**: Tau2 ~76.9%.

## Debilidades

- **Denso 31B**: más lento que MoE Flash de similar precio percibida (GLM-5.3-Flash, DeepSeek V4 Flash).
- **Sin audio** en variante 31B (solo E2B/E4B edge tienen audio).
- **Thinking en historial**: no incluir bloques `thought` de turnos previos en multi-turn (best practice Gemma).
- **HLE y tareas extremas**: por debajo de modelos trillion-class (Kimi K3, DeepSeek V4 Pro).
- **Sampling sensible**: Google recomienda `temperature=1.0` — desviarse puede degradar calidad.

## Parámetros de la API Ollama

### Thinking (Gemma 4)

Ollama abstrae la plantilla. En API nativa:

| Parámetro | Valores |
|-----------|---------|
| `think` | `true`/`false` o `low`/`medium`/`high`/`max` |

Comportamiento Gemma (documentación Google vía Ollama readme):

- Activar thinking: token `<|think|>` al inicio del system prompt (Ollama puede inyectarlo con `think: true`).
- En multi-turn: **no** reenviar contenido `thought` de turnos anteriores.

### Sampling oficial Gemma 4

| Parámetro | Valor recomendado Google |
|-----------|-------------------------|
| `temperature` | **1.0** |
| `top_p` | **0.95** |
| `top_k` | **64** |

### Multimodal

- Imágenes en `messages[].images` (base64).
- Colocar **imagen antes del texto** en el prompt.
- Presupuestos visuales (tokens): 70, 140, 280, 560, 1120 — mayor budget = más detalle OCR.

### Otros parámetros

| Parámetro | Notas |
|-----------|-------|
| `num_ctx` | hasta 262144 |
| `format` | `"json"` |
| `tools` | function calling |

### Ejemplo multimodal

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "gemma4:31b-cloud",
  "think": true,
  "stream": false,
  "messages": [{
    "role": "user",
    "content": "Describe la tabla de esta captura.",
    "images": ["<base64>"]
  }],
  "options": {
    "temperature": 1.0,
    "top_p": 0.95,
    "top_k": 64,
    "num_ctx": 131072
  }
}'
```

## Configuraciones recomendadas

| Caso de uso | think | temperature | top_p | num_ctx |
|-------------|-------|-------------|-------|---------|
| Chat general | true | 1.0 | 0.95 | 32768 |
| OCR / documentos | true | 1.0 | 0.95 | 65536+ |
| Coding | true | 0.8–1.0 | 0.95 | 65536 |
| Respuesta rápida sin CoT | false | 1.0 | 0.95 | 16384 |
| Agentes + tools | true | 1.0 | 0.95 | 131072 |

## Mejores usos

- Asistente **multimodal económico** (imagen + texto).
- Razonamiento matemático y código de nivel medio-alto sin coste frontier.
- Sustituto de Gemma 3 en pipelines existentes.
- Tareas con **system prompt estricto** (Gemma 4 mejora adherencia).
- Análisis de documentos largos hasta 256K.

## Integración en chatBot

- Respetar sampling Gemma (`temperature=1.0`) en presets; no forzar 0.8 genérico de Ollama.
- UI de thinking: mostrar canal `thought` separado si `think: true`.
- Vision: útil para analizar ilustraciones generadas o referencias visuales en chat.
- Añadir preset `gemma4:31b-cloud` en `config/ollama.json` con `num_ctx` max 262144.
