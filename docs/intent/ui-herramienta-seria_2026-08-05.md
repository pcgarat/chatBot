# Intent: UI como herramienta seria (conversación + panel derecho)

## Outcome

Que la app se sienta como una herramienta seria: ligera, minimalista, profesional — no como un chat web genérico. Paneles claros, controles agrupados, dark/light coherentes, color solo con intención.

## User

Tú, usándola a diario como cliente de chat/órdenes con Ollama (y providers).

## Why now

Hoy no transmite robustez: paneles difusos, controles sueltos (sobre todo conversación + lateral derecho), paleta sin intención clara.

## Success

En los primeros segundos se leen paneles delimitados, controles agrupados por función, modos dark y claro coherentes, e iconos/separadores con color funcional — sensación de herramienta de escritorio en el navegador.

## Constraint

Reestructurar el panel de conversación y el menú lateral derecho; sistema visual nuevo (tokens + tipografía/contraste); dark + light; detalles de color sobrios, sin sobrecargar.

## Out of scope

- Empaquetar Electron / app nativa.
- Rediseño profundo del sidebar izquierdo (solo alineación al sistema visual).
- Nuevas features de negocio.
- Móvil como prioridad de diseño.
